1. The Big Picture

Modern AI is not one thing. It is a family of systems built from a handful of ideas, and almost all of the systems you talk to — chatbots, code assistants, image generators, transcription, search — share the same skeleton: represent data as vectors, learn a scoring function from data, and repeat that function many times.

What a language model really is

A large language model (LLM) is a function that maps a sequence of tokens to a probability distribution over the next token. That is the entire contract. Everything else — the essays, the code, the summaries, the reasoning — is that one operation applied repeatedly.

p(tokent+1 | token1, …, tokent)  =  softmax( Wout · ht )

Where ht is a vector of numbers summarizing everything the model has read so far, and Wout is a learned matrix that scores every token in the vocabulary.

Three things it is not

  • Not a database lookup. It does not retrieve a stored answer; it computes a next-token distribution from scratch each time, conditioned on your prompt.
  • Not a rule engine. It has no hand-written symbol table, planner or verifier. Rules like "if the user greets, greet back" are not programmed; they are statistical regularities absorbed during training.
  • Not conscious, and not trained on your chat. Your prompt is processed at inference time. The weights are frozen unless the provider explicitly fine-tunes them.
Mental model to keep. The model is a differentiable program over vectors. Its output text is the path that program takes through probability space, one token at a time. Everything that looks like "understanding" is a byproduct of having learned an enormous number of statistical regularities over text, code, images and other modalities.

2. Tokens: the only input a model really gets

Neural networks accept numbers, never words. So before anything clever happens, your text is chopped into tokens — small chunks of characters with an integer ID from a fixed vocabulary.

Subword tokenization

Modern tokenizers (BPE, SentencePiece, WordPiece) are learned from the training corpus: frequent character pairs get merged into a single token. The result handles typos, rare names and any language without an "unknown" symbol.

"tokenization"   -> "token" "ization"          (2 tokens)
"photosynthesis" -> "photo" "synthesis"         (2 tokens)
"unbelievability"-> "un" "bel" "iev" "ab" "ility" (5 tokens)

Consequence. A token is neither a word nor a character. Models fail in peculiar ways because of it: rare spellings shatter across many tokens, and numbers may split into single digits, so arithmetic has to be learned over pieces.

3. Embeddings: IDs become meaning

Each token ID is looked up in a learned table — an embedding matrix — producing a dense vector of a few thousand numbers. This is the model's internal representation of a token in context-free form.

e(token) = E[token]     where E is a learned table of shape (vocab × d_model)

Three properties make these vectors powerful:

  • Similar meanings sit close together. "cat" and "dog" are nearer than "cat" and "invoice", so distance becomes a usable similarity metric.
  • Direction is meaning. Arithmetic on vectors corresponds to arithmetic on concepts: king − man + woman ≈ queen.
  • They are trainable. The embedding table is just another weight matrix, updated by gradient descent like everything else.
Mental model. An embedding is a point in a learned geometric space. Similar usage patterns push points together. The whole "meaning" of a word at this stage is its neighbourhood.

4. Neural networks: the machinery inside the transformer

A neural network is just a stack of matrix multiplications with a nonlinear "kink" inserted between them. Each layer takes a vector of numbers in and produces a vector of numbers out, and the weights inside each layer are tuned during training.

z = W x + b       (affine transformation)
h = φ(z)             (activation function)

For a single neuron, compute the weighted sum of the inputs, add a bias, then squash it. A layer stacks many such neurons. ReLU (max(0, x)) is the standard activation because it is cheap and trains well; modern models also use GELU and SiLU, which are smooth versions of the same idea.

Why the nonlinearity matters

Stack affine maps without a nonlinearity and you get an affine map — a single linear transformation no matter how many layers you add. The kink is what allows the network to represent curved, non-linear decision boundaries in high-dimensional space.

MatrixA stack of learned weights, e.g. 4096×4096 floats. Modern models contain tens of billions of these entries.
VectorOne token's representation. Shape [d_model], typically 1024 to 8192 floats.
BiasA learned offset per neuron. Small, but it lets a layer shift its output range.
Practical consequence. The expensive part of a transformer is not the "intelligence"; it is the sheer number of multiply-accumulate operations. This is why GPUs and TPUs matter, and why model pricing tracks parameters and tokens rather than abstract capability.

5. Self-attention: the core mechanism

Attention answers one question for every token: which other tokens in this sentence matter for understanding me? It does this with three learned matrices per head: WQ (query), WK (key) and WV (value).

Q = X WQ  ,  K = X WK  ,  V = X WV
Attention(Q, K, V) = softmax( (Q KT) / √dk ) V

Read it step by step for a single head:

  1. Project. Every token vector x becomes a query, a key and a value.
  2. Compare. The dot product q · k between two tokens measures how well they match. Dividing by √dk keeps the scores in a sane range so the softmax does not saturate.
  3. Normalize. Softmax turns the row of scores into weights that sum to 1 — this is the "attention distribution".
  4. Mix. Each token's output is the weighted average of all the value vectors, where the weights are the attention distribution.

Why the scaling term matters

Dot products of large vectors grow with dimension (roughly as √dk). Without the division, one large score dominates the softmax and all other weights collapse to zero, killing gradient flow. Scaling by 1/√dk is the standard fix from the original paper.

Causal masking

In a language model, position i may only attend to positions ≤ i. Everything to the right is masked out with a large negative number before the softmax. This makes the model causal: it cannot peek at the answer it is supposed to produce, and it forces the weights to encode "what came before".

Positional information

Attention alone is order-blind — it is a set operation. The original Transformer added learned positional embeddings to the token embeddings. Modern models mostly use rotary position embeddings (RoPE), which encode position by rotating the query and key vectors, letting attention interpolate smoothly to longer contexts.

Key idea. Attention is a content-based lookup: the query asks a question, the keys advertise what they answer, and the values carry the payload. Every capability that looks like reasoning is built on this one primitive.
